# todcubed blog

This repository hosts the microblogging website for `todcubed.github.io/blog`.

## Local preview

Open `index.html` in a browser or serve it with a simple local static server.

## GitHub Pages

To publish it on GitHub Pages:

1. Go to the repository settings.
2. Open `Pages`.
3. Select `Deploy from a branch`.
4. Choose the `main` branch and the root folder `/`.
5. Save.

The site will be available at:

https://todcubed.github.io/blog
